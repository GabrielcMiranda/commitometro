# ER-02 — Linha de rodapé (trailer)

## Identificação

Reconhece linhas de rodapé do Conventional Commits / git trailers e detecta
`BREAKING CHANGE`. Implementada em
[`src/commitometro/padroes/commits.py`](../../src/commitometro/padroes/commits.py),
função `validar_rodape`.

## Alfabeto (Σ)

- L = {A,…,Z} ∪ {a,…,z}
- W = `L L*`
- C e C₀ como na ER-01 (Σ − {\n} e Σ − {\n, ␣})

## Linguagem L

Um token (`BREAKING CHANGE` ou palavras de letras unidas por hífen simples), seguido do
separador `: ` ou ` #`, e de um valor não vazio que não começa com espaço.

## ER formal

```
( BREAKING␣CHANGE | W ( - W )* ) ( :␣ | ␣# ) C₀ C*
```

## Sintaxe implementada

```python
r"(BREAKING CHANGE|[A-Za-z]+(-[A-Za-z]+)*)(: | #)([^ \n][^\n]*)"
```

Grupos: 1 = token · 3 = separador · 4 = valor. Há quebra de compatibilidade se o token for
`BREAKING CHANGE` ou `BREAKING-CHANGE`.

## Equivalência (atalho → operador formal)

| Atalho no código | Operador formal |
|---|---|
| `BREAKING CHANGE\|[A-Za-z]+(-[A-Za-z]+)*` | união entre o literal e `W ( - W )*` |
| `[A-Za-z]` | classe finita, abreviação de L |
| `+` em `[A-Za-z]+` | `L L*` |
| `(: \| #)` | união `( :␣ \| ␣# )` |
| `[^ \n]`, `[^\n]` | classes negadas C₀ e C |

## Resultado e limitações

Todos os 17 casos passam, com 99% de cobertura de `commits.py` (só falta a linha do
fallback defensivo de `diagnosticar_cabecalho`, em `analise.py`, não desta ER). Limitação
conhecida: a ER aceita qualquer token formado só por letras como se fosse um trailer
válido — ela não valida contra uma lista fechada de nomes de trailer reconhecidos (como
`Reviewed-by`, `Signed-off-by`), então um token inventado do tipo `Xyz-by: valor` também é
aceito.
